Privacy Policy

Last updated: 2026-10-07

Summary

Deep Cloner runs entirely inside your Salesforce org. It does not send data to the developer or to any third party.

Data we collect

None. The application has no external servers, no analytics, no tracking and no callouts to external services. The developer has no access to your Salesforce org or data.

Data stored in your org

The only data the application stores is its own configuration (maximum records per clone and a list of excluded objects) in the custom setting Deep_Cloner_Settings__c. Records you clone are created in your own org according to your permissions.

Access control

All operations run in user mode, so Salesforce object permissions, field-level security and sharing rules apply to every user.

Changes

If this policy changes, the new version will be published on this page with an updated date.
