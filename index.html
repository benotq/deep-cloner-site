Deep Cloner

Deep-clone a Salesforce record together with the related records you pick, from a button in the record's Actions menu.

Features

  • Lazy tree of child objects, up to 4 levels deep.
  • References between cloned records are remapped automatically.
  • Everything rolls back if any record fails.
  • Runs in user mode: the user's CRUD, field-level security and sharing always apply.
  • Search and sort the related objects, and select every match at once.
  • Live count of the records a clone will create, checked against your limit before you click Clone.
  • Saved selections: apply a favourite choice in one click.
  • Files and Notes: link the same files to the copy, or duplicate them.
  • Clone several records at once from a list view.
  • Deep Clone tab: choose an object and a record without any page layout change.
  • Admin settings: maximum records per clone and a list of excluded objects.

Permission sets

  • Deep Cloner User: use the Deep Clone quick action.
  • Deep Cloner Admin: everything above, plus the Deep Cloner app and its settings.

Add the button to any object

Setup → Object Manager → your object → Buttons, Links, and Actions → New Action → type Lightning Web Component → c:deepCloner, then add it to the page layout.
